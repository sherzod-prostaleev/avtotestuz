# M2-09 Checkout UI & Status Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Implement the full frontend checkout flow: Provider picker (Payme/Click), promo code validation and discount preview UI on `/premium`, free zero-amount checkout redirection, and checkout result pages (`/checkout/success`, `/checkout/failure`, `/checkout/pending`).

**Architecture:** Next.js 14 App Router, TypeScript, Tailwind CSS, i18n (`next-intl`), Vitest + Testing Library.

## Global Constraints
- `npm run typecheck` and `npm run test` must pass cleanly.
- Support 3 locales: `uz-Latn`, `uz-Cyrl`, `ru`.
- Premium dark theme design system (#0E1526, Indigo accent, Gold VIP badge).
- Clean handling of 0 UZS free promo checkout vs external Payme/Click checkout redirect.
